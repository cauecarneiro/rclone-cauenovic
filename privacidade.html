Política de Privacidade

Última atualização: 14 de outubro de 2026.

O que é este aplicativo

"rclone cauenovic" é uma ferramenta pessoal de Cauê Carneiro. Ela conecta o programa rclone à conta do Google Drive do próprio autor para enviar, baixar e conferir arquivos de um projeto de criação de conteúdo. Não há outros usuários.

Quais dados são acessados

O aplicativo solicita acesso aos arquivos do Google Drive do autor (escopo drive) e lê e grava apenas esses arquivos, na conta do autor.

Como os dados são usados

Os dados são usados somente para o envio, o download e a conferência dos arquivos do próprio autor. Nada é coletado para outro fim, e nenhum dado é enviado a servidores do aplicativo, porque não existe servidor: tudo roda no computador do autor.

Compartilhamento e armazenamento

Nenhum dado é vendido, compartilhado ou transferido a terceiros. As credenciais de acesso ficam guardadas apenas no arquivo de configuração do rclone no computador do autor.

Conformidade com a política do Google

O uso e a transferência, para qualquer outro aplicativo, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions.
